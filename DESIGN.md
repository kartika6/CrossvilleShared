# CrossvilleShared design

Inherit the existing Crossville light workspace, visually inspected on November 9, 2026. This surface is an operational connector preview rather than a marketing page.

- White and very pale blue-gray surfaces; ink text; blue active states.
- A compact left project/navigation rail, central working surface and context inspector on wide screens.
- Preserve generous reading space around the user's task and make the next action unambiguous.
- Fine borders establish regions. Reserve elevation for the confirmation dialog.
- Use a system sans-serif face, comfortable body text and compact uppercase metadata labels sparingly.
- Every color state has a text label. Keyboard focus stays visible.
- A short pipeline shows request, context selection, preview and return. It represents actual application state.
- Sources, current versions and exclusions are accessible without dominating the task.
- On narrow screens, collapse the left navigation and place the inspector below the working surface. No sideways scrolling is required.
